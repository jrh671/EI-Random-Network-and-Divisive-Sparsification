README: L.I.F. EI Random Network And DivSparse Simulations\

Codebase for findings from "Effective computations for hippocampal place cell phenomena in sparse untrained random networks". Jose Hurtado, SueYeon Chung, Andre Fenton (2025).\

1) To run PreSimulated data and generate figures, the relevant data must be saved in the correct subfolder.\

Link to Data: (enter link here)\

The Data folder contains the folder structure at the level that data should be saved, for example: 'Figure_1/1F/PreRun_Data/' in the code base directory is an empty folder that is matched to a data folder with an analagous directory. \

2) Each figure script provides an option to run new simulations instead of pre loading saved data. Each Figure folder contains a RunNew.txt with specific instructions for using the code.\

3) To use PreRun data, replace the directory with the relevant directory where data was saved.\

4) Article Link: https://www.biorxiv.org/content/10.1101/2025.10.04.680487v1
